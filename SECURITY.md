# Segurança

Não publique tokens ou dados pessoais em issues. Para vulnerabilidade sensível, use o canal privado de reporte de segurança do GitHub se estiver habilitado; caso contrário contate o mantenedor pelo perfil para combinar um canal privado. Não há canal privado próprio configurado neste repositório.

A aplicação limita AST e interrompe worker após oito segundos; não aceita código JavaScript. Isso não prova ausência de vulnerabilidades. Não use como única fonte em decisões críticas. Atualize dependências com CI, revisão e auditoria de vulnerabilidades.
