# Privacidade

Os cálculos ocorrem no dispositivo. O aplicativo não inclui analytics, cookies de rastreamento ou API matemática remota. O histórico guarda até 20 resultados em localStorage e pode ser apagado no botão da tela. Cache offline guarda arquivos do aplicativo, não sincroniza histórico entre dispositivos.

O provedor de hospedagem pode registrar acessos e IP conforme suas políticas. Links para GitHub/Netlify levam a serviços externos. Limpar dados do site remove o histórico/cache. Não há conta, backup remoto ou garantia de recuperação.
